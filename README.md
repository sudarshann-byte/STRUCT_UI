# 🚀 STRUCT-UI - HTML5 Admin Dashboard Template

![License](https://img.shields.io/badge/license-MIT-blue.svg) ![Version](https://img.shields.io/badge/version-2.1.8-green.svg) ![Size](https://img.shields.io/badge/size-lightweight-orange.svg)

Link : https://struct-ui.vercel.app/

**Struct UI** is a comprehensive, responsive, and high-performance Admin Dashboard template built using **pure HTML5, CSS3, and Vanilla JavaScript**. No complex build tools, no frameworks dependencies—just clean, modular, and easy-to-customize code.

Ideal for building Admin Panels, SaaS Dashboards, E-commerce Backends, and CMS interfaces.

---

## ✨ Key Features

### 🎨 Core Features
- **Zero Dependencies:** Built with Vanilla JS & CSS Variables.
- **Dark & Light Mode:** Seamless toggle with local storage persistence.
- **Fully Responsive:** Mobile-first design with collapsible sidebar.
- **Modular Structure:** Organized code for easy scalability.

### 📊 Dashboard & Analytics
- **Interactive Charts:** Integrated with Chart.js.
- **CRM Analytics:** Traffic sources, sales overview, and performance metrics.
- **E-commerce:** Product management, Kanban board for orders, and Invoice generation.

### 🔐 Authentication Pages
- Login & Register
- Forgot & Reset Password
- Two-Step Verification (OTP)
- Lock Screen

### 🧩 UI Components
- **Data Tables:** with sorting, filtering, and pagination.
- **Forms:** Input groups, switches, sliders, and file uploads.
- **Cards & Modals:** Various styles for diverse use cases.
- **Notifications:** Toast messages and dropdown alerts.
